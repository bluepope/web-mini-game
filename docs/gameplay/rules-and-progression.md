# 게임 규칙과 진행

## 게임판

실제 참가자 n명이 각각 개구리 한 마리를 조종하고, 연꽃잎은 총 n+1개입니다. 개구리와 연꽃잎은 원형으로 배치하며 모든 개구리는 중앙을 바라봅니다. 항상 정확히 하나의 연꽃잎이 비어 있습니다.

연꽃잎 i의 중심은 중심 C, 보드 반지름 R, 슬롯 수 m=n+1에 대해 다음과 같습니다.

```text
angle(i) = initialRotation + 2πi/m
slot(i) = C + R × (cos(angle(i)), sin(angle(i)))
```

방장은 2~8명의 플레이어가 모두 연결되고 참가자들이 준비되었을 때 1·3·5라운드 경기를 시작합니다. 턴 순서는 경기를 시작할 때 확정하고, 플레이어의 슬롯 위치가 바뀌어도 그대로 유지합니다. 경기 중 들어온 사람은 해당 경기에 참가할 수 없습니다.

## 점프와 판정

조작은 버튼 하나뿐입니다. 키보드·마우스·터치는 같은 점프 명령을 보냅니다. 방향 화살표는 현재 플레이어를 기준으로 좌우 왕복하고, 버튼을 누른 시점의 각도로 서버가 착지 경로를 판정합니다.

점프 거리는 출발점에서 배치 원을 다시 만나는 교점을 사용합니다. 출발 위치 P와 안쪽 단위 방향 d에 대해:

```text
distance = -2 × dot(P - C, d)
landing = P + distance × d
```

서버가 다음 순서로 판정합니다.

1. 개구리 이동 선분과 다른 개구리의 충돌 반경을 검사합니다. 충돌하면 `collision`이며 상대 플레이어의 위치는 유지됩니다.
2. 충돌하지 않고 빈 연꽃잎 중심에서 유효 성공 반경 안에 착지하면 `success`입니다. 유효 반경은 `max(padRadius - frogRadius, padRadius × 0.82)`입니다.
3. 나머지는 `water`입니다.

빈자리 안의 점선은 성공 반경을 표시합니다. 점선 근처에 착지해도 성공하도록 중심 판정 영역을 연꽃잎의 82%까지 넓혔습니다. 이 관용 범위는 모든 방향에 똑같이 적용되며 개구리 간 충돌 판정에는 영향을 주지 않습니다.

성공하면 도착 슬롯을 차지하고 출발 슬롯이 새로운 빈자리가 됩니다. 충돌·물·시간 초과 실패 시에는 현재 슬롯을 유지합니다. 한 턴 제한은 10초입니다. 결과는 점프 애니메이션 후 서버가 확정합니다.

## 멀티플레이 라운드

1라운드는 **모든 참가자가 한 번씩 점프한 뒤**, 마지막 점프의 결과나 마지막 플레이어의 제한 시간이 확정될 때 완료됩니다. 라운드 중에는 참가자 모두 같은 왕복 속도를 사용합니다.

| 라운드 | 직전 라운드 대비 속도 | 화살표 주기 |
| --- | ---: | ---: |
| 1 | 1.00배 | 4400ms |
| 2 | 1.10배 | 4000ms |
| 3 | 1.21배 | 약 3636ms |
| k | `1.1^(k-1)`배 | `4400 / 1.1^(k-1)`ms |

실패해도 플레이어는 그 라운드의 시도를 완료한 것으로 처리합니다. 라운드가 끝난 뒤에도 슬롯과 빈자리는 유지합니다. 다음 라운드에서는 첫 플레이어부터 순서대로 다시 시도합니다. 경기 종료 후 총 성공 횟수가 가장 많은 플레이어가 우승하며 동점은 공동 순위입니다. 새 경기는 항상 1라운드 기본 속도로 시작합니다.

보드도 라운드에 맞춰 펼쳐집니다. 슬롯 사이 거리를 나타내는 원형 보드 반지름은 첫 라운드의 `1.7`에서 마지막 라운드의 `2.7`까지 매 라운드 같은 폭으로 증가합니다.

| 라운드 수 | 라운드별 보드 반지름 |
| --- | --- |
| 1 | 1.7 |
| 3 | 1.7 → 2.2 → 2.7 |
| 5 | 1.7 → 1.95 → 2.2 → 2.45 → 2.7 |

서버가 확정한 보드 반지름에 맞춰 플레이어와 연꽃잎을 함께 배치합니다. 라운드 사이에는 새 간격으로 부드럽게 이동합니다. 연꽃잎 자체 크기와 성공 판정 범위는 바뀌지 않습니다. 연습 모드는 보드 반지름을 2.7로 고정합니다.

## 연습 모드

연습 모드는 플레이어 한 명과 고정된 연습 개구리 세 마리, 빈 연꽃잎 하나로 진행합니다. 한 번의 점프나 시간 초과가 끝나면 같은 플레이어 차례로 돌아오며 라운드 제한은 없습니다. 점프 속도는 기본 4400ms로 고정되어 있고, 실패 시 위치를 유지합니다. 성공·시도 횟수와 성공률은 실제 플레이어 기준으로 집계합니다. 연습 방은 비공개이며, 연습 도중 나가면 방을 정리합니다.
